# Mongongo Way

La plateforme musicale des musiciens de **Theway RDC** : écoute gratuite, téléchargement payant par Mobile Money, échanges entre musiciens et croyants.

Application web (PWA) en HTML / CSS / JavaScript, reliée à une base **Supabase**.

## Fonctions (version 1)
- Inscription et connexion par numéro de téléphone + mot de passe
- Écoute gratuite des titres publiés, recherche, lecteur avec contrôle sur l'écran verrouillé
- J'aime et commentaires
- Espace artiste : demande de fiche, dépôt de titres (audio, pochette, paroles), statistiques
- Administration : validation des artistes et des titres, réglage des tarifs
- Installation sur l'écran d'accueil du téléphone

## Fichiers
| Fichier | Rôle |
|---|---|
| `index.html` | Page unique de l'application |
| `style.css` | Apparence |
| `app.js` | Toute la logique (écrans, lecteur, Supabase) |
| `manifest.json`, `sw.js`, `icons/` | Installation sur téléphone et fonctionnement hors ligne |
